# Premier essai du script version 4

Ce script a pour but de mettre en place la possibilité de choisir dans quel dossier j'enregistre mon compte rendu Markdown. 
Je peux aussi choisir le nom que va porter ce fichier.

Pour ce faire, j'ai mis en place un système qui permet de manière constante de trouver le chemin qui va servir à enregistrer le fichier du Markdown en partant du chemin du script dans l'arbor essence.

Ainsi, peu importe depuis quel dossier ou répertoire je lance le script, il va toujours fonctionner et enregistrer le fichier Markdown au bon endroit.
