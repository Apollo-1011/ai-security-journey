# Test de lancement du script 4 avec un fichier de type bat

Ceci est le premier test de lancement du script 4 avec un fichier de type bat.
L'enjeu de ce test est de vérifier le fonctionnement du script à partir d'un fichier bat qui est sur mon bureau.
Je fais donc tous les tests pour m'assurer que cette première version définitive de mon script est opérationnelle.

## Liste des tests réalisés

*   Vérification de la lecture du fichier bat
*   Vérification de la lecture des informations contenues dans le fichier bat
*   Vérification de l'application des transformations nécessaires

Il s'agit de la première étape pour garantir que le script fonctionne correctement sur différentes configurations.
